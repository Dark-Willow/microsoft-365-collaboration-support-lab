# Ticket 01 - Microsoft Teams Sign-in Issue

## Ticket Details

| Field | Value |
|---|---|
| Type | Incident |
| Priority | Medium |
| Application | Microsoft Teams |
| Requester | HR User One (simulated) |

## Issue Summary

A user reports being unable to sign in to Microsoft Teams.

## Reported Symptoms

- Teams repeatedly requests authentication
- User cannot access team channels
- Outlook access may still be working

## Troubleshooting Plan

1. Verify the user's identity.
2. Check the account in Microsoft 365 Admin Centre.
3. Review sign-in status.
4. Confirm Microsoft 365 licence and Teams service access.
5. Test Teams through a browser.
6. Review the authentication error.
7. Check Microsoft 365 service health.
8. Escalate if the issue remains unresolved.

## Expected Resolution

Restore Teams access after identifying and correcting the cause, subject to appropriate authorisation.

## Verification

Ask the user to confirm that they can sign in and access the required team.

## Lab Note

This is a simulated support ticket. No actual Teams sign-in failure was reproduced or resolved.
