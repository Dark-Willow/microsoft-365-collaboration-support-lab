# Ticket 02 - Microsoft Teams Channel Access

## Ticket Details

| Field | Value |
|---|---|
| Type | Service Request |
| Priority | Medium |
| Application | Microsoft Teams |
| Requester | IT Support One (lab user) |
| Status | Lab Exercise |

## Issue Summary

A user requires access to the Support Requests channel in Microsoft Teams.

## Lab Activities

- Opened the IT Support Labs team
- Reviewed existing team members
- Reviewed team member roles
- Checked General channel settings
- Created a standard channel named Support Requests
- Posted a test message
- Reviewed channel details

## Support Procedure

1. Confirm the required team and channel.
2. Review the user's team membership.
3. Identify whether the channel is standard, private or shared.
4. Confirm that the user has the appropriate access.
5. Make authorised membership changes if needed.
6. Ask the user to open the channel.

## Lab Outcome

The Support Requests standard channel was created and a test message was posted.

## Verification

Channel creation and posting were documented. Access from another user's account would require separate verification.

## Skills Demonstrated

- Microsoft Teams administration
- Team membership review
- Channel management
- User access support
