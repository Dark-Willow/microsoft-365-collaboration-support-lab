# Ticket 05 - OneDrive Synchronisation Issue

## Ticket Details

| Field | Value |
|---|---|
| Type | Incident |

| Requester | Finance User One (simulated) |

## Issue Summary

A user reports that files on their computer are not synchronising with OneDrive cloud storage.

## Reported Symptoms

- Files appear online but not locally
- Synchronisation appears paused
- Recent document changes are missing
- OneDrive may display a sync error

## Troubleshooting Plan

1. Verify the affected account and device.
2. Check internet connectivity.
3. Open OneDrive on the web.
4. Confirm the files are available online.
5. Review the OneDrive desktop sync status.
6. Check whether synchronisation is paused.
7. Review available storage.
8. Confirm the correct account is signed in.
9. Check for sync error messages or conflicting files.
10. Restart or update OneDrive if appropriate.
11. Escalate persistent issues.

## Data Protection

Check for unsynchronised local changes before resetting OneDrive, unlinking accounts or removing files.

## Expected Resolution

Restore file synchronisation and confirm changes appear correctly in both local and cloud storage.

## Verification

Confirm that an approved test file synchronises successfully.

## Lab Note

This ticket documents a hypothetical troubleshooting scenario. An actual desktop synchronisation failure was not reproduced.
