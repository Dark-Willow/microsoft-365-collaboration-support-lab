# Ticket 03 - OneDrive File Sharing Request

## Ticket Details

| Field | Value |
|---|---|
| Type | Service Request |
| Priority | Low |
| Application | Microsoft OneDrive |
| Requester | HR User One (lab user) |
| Status | Lab Exercise |

## Issue Summary

A user requires view-only access to a document stored in OneDrive.

## Lab Activities

- Created the Collaboration Support Lab folder
- Created the Support Test Document
- Opened file sharing settings
- Selected HR User One
- Selected Can view permissions
- Sent the sharing invitation
- Reviewed Manage access
- Removed temporary sharing access

## Support Procedure

1. Verify the file and intended recipient.
2. Confirm that sharing is authorised.
3. Open the document's sharing settings.
4. Select the specific recipient.
5. Apply the minimum required permission.
6. Send the sharing invitation.
7. Review Manage access.
8. Remove access when no longer required.

## Lab Outcome

View-only sharing and access management were practised in OneDrive.

## Verification

Sharing configuration and access changes were documented through screenshots. Recipient-side access would require separate testing.

## Skills Demonstrated

- OneDrive administration
- File sharing
- Access permissions
- Least-privilege access
- Service Desk documentation
