# Ticket 04 - SharePoint Document Access

## Ticket Details

| Field | Value |
|---|---|
| Type | Service Request |
| Priority | Medium |
| Application | SharePoint Online |
| Requester | Finance User One (simulated) |

## Issue Summary

A user reports that they cannot open a document stored in a SharePoint document library.

## Possible Causes

- Missing site membership
- Incorrect document permissions
- Unique folder or file permissions
- Incorrect Microsoft 365 account
- Sharing restrictions

## Relevant Lab Activities

- Opened a SharePoint site
- Reviewed site permissions
- Accessed a document library
- Created a test folder and document
- Reviewed file sharing settings
- Reviewed Manage access

## Troubleshooting Plan

1. Confirm the affected SharePoint site and document.
2. Check whether the user can access the site.
3. Review site membership.
4. Check document library permissions.
5. Review file-level access.
6. Determine whether permissions are inherited.
7. Apply approved changes if required.
8. Ask the user to verify access.

## Expected Resolution

Ensure the user has the correct authorised access to the requested document.
