# Lab 01 - Collaboration Support Lab Setup

## Objective

The objective of this lab is to confirm that the Microsoft 365 environment is ready for collaboration support tasks.

This lab checks access to Microsoft 365 Admin Centre, active users, the Microsoft 365 app launcher, Teams, OneDrive, and SharePoint.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft 365 |
| Admin Tool | Microsoft 365 Admin Centre |
| Collaboration Apps | Teams, OneDrive, SharePoint |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Opened Microsoft 365 Admin Centre
- Confirmed access to the admin dashboard
- Reviewed active users for the collaboration lab
- Opened the Microsoft 365 app launcher
- Confirmed Teams, OneDrive, and SharePoint were available
- Opened Microsoft Teams in the browser
- Opened OneDrive in the browser
- Opened SharePoint in the browser
- Captured screenshots for documentation

## What I Learned

In this lab, I learned how to confirm that a Microsoft 365 tenant is ready for collaboration support tasks.

I checked that users were available in Microsoft 365 Admin Centre and confirmed that key collaboration apps such as Teams, OneDrive, and SharePoint could be opened from the Microsoft 365 app launcher.

This setup is important because collaboration support issues often involve user access, file sharing, Teams access, OneDrive storage, and SharePoint sites.

## IT Support Relevance

Service Desk technicians often support Microsoft 365 collaboration tools.

Before troubleshooting Teams, OneDrive, or SharePoint issues, it is important to confirm that the user account exists, the apps are available, and the services can be accessed through the browser.
