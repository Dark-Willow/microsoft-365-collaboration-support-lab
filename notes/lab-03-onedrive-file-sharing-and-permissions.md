# Lab 03 - OneDrive File Sharing and Permissions

## Objective

The objective of this lab is to practise basic OneDrive file sharing and permissions support tasks.

This lab focuses on creating a test folder, creating a test document, sharing the file with a lab user, reviewing sharing permissions, and removing access.

## Lab Environment

| Component | Details |
|---|---|
| Platform | Microsoft OneDrive |
| Folder Used | Collaboration Support Lab |
| Test File | Support Test Document |
| Test User | HR User One |
| Role Practised | Entry-level IT Support / Service Desk technician |

## Tasks Completed

- Opened OneDrive in the browser
- Created a test folder called Collaboration Support Lab
- Created a test document called Support Test Document
- Added basic test content to the document
- Opened file sharing settings
- Shared the file with HR User One
- Set the permission to Can view
- Reviewed manage access settings
- Removed sharing access
- Captured screenshots for documentation

## What I Learned

In this lab, I learned how to manage basic OneDrive file sharing and permissions.

I practised creating a folder and document, sharing a file with a specific user, selecting view-only permissions, reviewing who has access, and removing access when it is no longer required.

This helped me understand how file sharing issues can be checked and documented in a Microsoft 365 support environment.

## IT Support Relevance

OneDrive file sharing issues are common in Service Desk roles.

Users may need help sharing files, changing permissions, checking who has access, or removing access from a file. IT Support technicians should understand how to review sharing settings and confirm whether users have the correct permissions.
