# Microsoft 365 Collaboration Support Lab

## Project Overview

This repository documents a hands-on Microsoft 365 collaboration support lab focused on common IT Support and Service Desk scenarios.

The purpose of this project is to practise Microsoft 365 collaboration support tasks involving Teams, OneDrive, SharePoint, file sharing, user access, permissions, sync issues, and support documentation.

This lab is designed to show practical understanding of how Microsoft 365 collaboration issues are investigated, documented, and supported in an entry-level IT Support environment.
