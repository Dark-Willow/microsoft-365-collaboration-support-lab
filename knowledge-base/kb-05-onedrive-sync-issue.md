# KB 05 - OneDrive Synchronisation Issue

## Issue Summary

A user reports that files are not synchronising between their computer and OneDrive cloud storage.

## Common Symptoms

- Files do not update across devices
- OneDrive displays a sync error
- Files are available online but missing locally
- OneDrive displays a paused or disconnected status
- Uploads remain pending
- Files show conflicting versions

## Possible Causes

- Internet connectivity problem
- OneDrive sync paused
- User signed into the wrong account
- Insufficient storage
- Invalid file names or unsupported file conditions
- OneDrive application issue
- File conflict or permission problem

## Troubleshooting Steps

1. Confirm the affected user and device.
2. Check whether the file is available in OneDrive on the web.
3. Confirm internet connectivity.
4. Check the OneDrive sync status icon on the device.
5. Confirm synchronisation is not paused.
6. Check for specific sync error messages.
7. Confirm the correct Microsoft 365 account is signed in.
8. Review available OneDrive storage.
9. Review the affected file's name, permissions and location.
10. Restart the OneDrive application if appropriate.
11. Review application updates and Microsoft guidance for the specific error.
12. Escalate persistent synchronisation or data-conflict issues.

## Data Protection Note

Do not delete local files, reset synchronisation or unlink accounts without first checking for unsynchronised changes and following the organisation's approved procedure.

## Verification

Confirm that a test file or approved existing file synchronises correctly between OneDrive on the web and the affected device.

## Resolution Documentation

Document the sync error, troubleshooting actions, verification result and any outstanding issues.
