# KB 02 - Microsoft Teams Channel Not Visible

## Issue Summary

A user reports that they cannot find a Microsoft Teams channel.

## Common Symptoms

- Team is missing
- Channel is not visible
- User cannot access a private channel
- User receives a permissions error
- Channel is visible to colleagues but not the affected user

## Possible Causes

- User is not a member of the team
- Channel is hidden
- User is not a member of a private or shared channel
- User is signed into the wrong Microsoft 365 account
- Membership changes have not yet taken effect
- Teams application has not refreshed

## Troubleshooting Steps

1. Confirm the team and channel names.
2. Confirm the affected user account.
3. Open the team in Microsoft Teams.
4. Review team membership.
5. Check whether the user belongs to the team.
6. Check whether the channel is standard, private or shared.
7. For standard channels, confirm team membership and check whether the channel is hidden.
8. For private or shared channels, review the channel's membership and applicable access requirements.
9. Ask the user to refresh Teams or sign in through the browser.
10. Escalate if access remains unavailable despite correct membership.

## Important Permission Note

Standard channels are accessible to members of the parent team.

Private channels have separate membership.

Shared channels have separate membership and may involve users outside the parent team.

## Verification

Confirm that the affected user can locate and open the required channel.

## Resolution Documentation

Record the channel type, membership findings, changes made and user confirmation.
