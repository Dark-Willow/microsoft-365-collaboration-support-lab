# KB 03 - OneDrive File Sharing Issue

## Issue Summary

A user reports that another person cannot access a file shared through Microsoft OneDrive.

## Common Symptoms

- Recipient cannot open a shared file
- Access denied message
- User has view-only access instead of editing permissions
- Sharing link does not work
- User cannot find a previously shared document

## Possible Causes

- Incorrect recipient selected
- Sharing permissions not configured correctly
- Sharing link expired or was removed
- Recipient is signed into the wrong account
- Organisation sharing policy restricts access
- File or folder permissions were changed

## Troubleshooting Steps

1. Confirm the affected document and recipient.
2. Open OneDrive using the file owner's account or approved administrator access.
3. Locate the document.
4. Open Manage access.
5. Review existing sharing links and direct access.
6. Confirm the intended recipient has appropriate access.
7. Review whether Can view or Can edit is required.
8. Check the link type and any relevant sharing restrictions.
9. Update access only with the file owner's or appropriate administrator's authorisation.
10. Ask the recipient to test opening the document again.

## Security Considerations

- Prefer specific people over unrestricted sharing links.
- Apply least-privilege permissions.
- Avoid granting editing access unnecessarily.
- Remove access when it is no longer required.

## Verification

Confirm that the intended recipient can open the document with the correct level of access.

## Resolution Documentation

Record the original permissions, changes made, approved access level and verification result.
