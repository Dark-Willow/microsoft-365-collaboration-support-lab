# KB 01 - Microsoft Teams Access Issue

## Issue Summary

A user reports that they cannot access Microsoft Teams or sign in to the Teams application.

## Common Symptoms

- Teams does not open
- User cannot sign in
- Teams repeatedly requests authentication
- User receives an access error
- Teams works in the browser but not the desktop application

## Possible Causes

- Incorrect account credentials
- User account is blocked
- Microsoft Teams licence or service access issue
- MFA authentication problem
- Browser or desktop application issue
- Microsoft Teams service outage

## Troubleshooting Steps

1. Confirm the affected user and exact error message.
2. Check the user account in Microsoft 365 Admin Centre.
3. Confirm sign-in is allowed.
4. Review the assigned Microsoft 365 licence and Teams service access.
5. Ask the user to test Teams in a browser.
6. Check whether other Microsoft 365 applications work.
7. If only the desktop app fails, restart Teams and review application updates.
8. Check Microsoft 365 service health if multiple users are affected.
9. Escalate unresolved authentication or service issues.

## Verification

Ask the user to sign in and confirm that their Teams chats and channels are accessible.

## Resolution Documentation

Record the cause, checks performed, actions taken and user confirmation. Do not mark the issue resolved unless access has been verified.
